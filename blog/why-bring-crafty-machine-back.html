Why bring Crafty Machine back

Because owning the domain and publishing simply is better than leaving the whole thing in limbo.

Back to blog Home

Crafty Machine has been dormant long enough. The old hosting setup decayed, the DNS drifted, and email stopped being reliable. None of that was a content problem. It was infrastructure drag.

The fix is to make the stack smaller. GitHub Pages handles the site. GoDaddy handles DNS. Google Workspace handles mail. Each piece does one job, and the setup is easy to reason about later.

This version of the site starts with almost no ceremony: a homepage, a blog, and a way to keep publishing without waiting on a redesign or a CMS migration. More structure can come later if it earns its keep.

For now, the important part is that Crafty Machine exists again and is easy to maintain.
